# Smart Health & Kitchen Assistant

A web application that helps users manage kitchen inventory and medicine stock in one place. It tracks expiry dates, monitors low stock, and helps users stay organized.

## Live Demo

🌐 **Application:** https://smart-health-and-kitchen-assistant-1mfq.onrender.com

## Features

### User Authentication
- User sign up and login
- Separate inventory for each user
- Secure session handling

### Kitchen Inventory
- Add, edit, and delete food items
- Track expiry dates
- Color-coded expiry status
- Low stock detection
- Search functionality

### Medicine Inventory
- Add, edit, and delete medicines
- Track expiry dates
- Low stock alerts
- Search medicines

### Dashboard
- Inventory summaries
- Total items
- Low stock count
- Expired items count

## Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Database: SQLite
- Deployment:
  - Frontend: Render
  - Backend: Render
- Version Control: Git & GitHub

## Installation

1. Clone the repository
   ```bash
   git clone <https://github.com/preranav1011-blip/Smart-Health-and-Food-Assistant>
   ```

2. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```

3. Start the Flask server
   ```bash
   python app.py
   ```

4. Open the frontend in your browser.
